Interface to test, validate and iterate over the duel system of the game I'm developing in Godot  

Prone to big changes from one version to another  
Might not entirely reflect the mechanics that will be available for the complete game  

Designed here as local 1v1 PvP, might introduce ai fights in the future for further testing (as the game will be PvE anyway)  
Designed with tablet in mind so made to be installed as a PWA  

If you ever want to test it out: https://heavylab.github.io/duels-interface/
